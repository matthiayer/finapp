Local CSV Sanitizer

Prepare a separate, sanitized copy of a bank CSV on this device.

Privacy first

This page has no network code and does not upload your file. Values are redacted by default. Column names are kept; review the output before sharing. Any column you choose to keep is copied unchanged and may contain sensitive information.

Repeated values in a redacted column receive the same placeholder in this copy. The placeholder mapping is not saved.

1. Choose a CSV

For safety, the default treats every record as data and uses generic column names. If you select a header row, its names are preserved unchanged; inspect them before sharing. Records before that header are omitted. The output is UTF-8 CSV using the selected delimiter.

2. Review columns

All values will be redacted unless you explicitly keep a column unchanged. Dates and amounts can also be sensitive; keep them only if you have reviewed that choice.

For the CSV you described

Account numbers/names, counterparty account, transaction number, and description/message fields should normally remain redacted. The page redacts every column by default, including columns not recognized by name.
